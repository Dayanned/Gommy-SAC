# 📖 Descripción

Gommy SAC es una tienda virtual diseñada para ofrecer una experiencia de compra moderna e intuitiva de gomitas funcionales sabor maracuyá.

La aplicación permite al usuario navegar por el catálogo de productos, agregarlos al carrito, completar un proceso de compra simulado, seleccionar su ubicación mediante un mapa interactivo, generar una boleta en PDF y enviar automáticamente el pedido mediante WhatsApp.

Además, incorpora un **Test de Bienestar Gommy**, una herramienta interactiva que brinda recomendaciones generales sobre el bienestar emocional del usuario.

Este proyecto fue desarrollado únicamente con fines educativos como parte de una presentación universitaria.

---

# 🎯 Objetivos

- Simular un proceso completo de compra.
- Ofrecer una interfaz moderna y amigable.
- Implementar un carrito de compras funcional.
- Simular métodos de pago mediante Yape y Plin.
- Generar automáticamente una boleta en PDF.
- Integrar WhatsApp para enviar pedidos.
- Incorporar un cuestionario interactivo de bienestar.
- Desarrollar una aplicación completamente responsive.

# 🚀 Instalación

Clonar el repositorio

```bash
git clone https://github.com/TU-USUARIO/gommy-sac.git
```

Ingresar al proyecto

```bash
cd gommy-sac
```

Instalar dependencias

```bash
npm install
```

Ejecutar el proyecto

```bash
npm run dev
```

Compilar para producción

```bash
npm run build
```
